# Plan

Write a short plan before any change that touches several files or the structure of this workspace. Planning only: change nothing else until I say go.

## Variables

request: $ARGUMENTS (what I want to change or build)

## Steps

1. Read `AGENTS.md` and what the request touches. If anything is unclear, ask me up to three short questions first.
2. Write `plans/YYYY-MM-DD-short-name.md` (today's date, kebab-case name) with exactly these headings:
   - **Goal:** one or two sentences.
   - **Steps:** a numbered list, each step small enough to check.
   - **Files:** the files that will be created or changed. Mark any protected file (see `AGENTS.md`): I make that change myself.
   - **Risks:** what could go wrong, and how I would undo it.
   - **Status:** `Draft`.
3. Show me the plan and ask for a go or changes. Do not start the steps yet.
4. When I say go: do the steps in order, tell me after each one, set **Status** to `Done` (or `Stopped: reason`) at the end, and report what changed.

## Rules

- A plan holds no secrets and no personal data.
- If a step needs a protected file, a purchase or anything leaving this folder, stop there and ask.
